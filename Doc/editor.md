#### Clear
- 프로젝트를 모두 비우는 버튼

#### Reload
- 등록되어있는 루아스크립트를 모두 다시 로드하는 버튼

#### Save
- 현재 상태의 프로젝트(nkmod.json, nkmod.bin)를 저장하는 버튼 (json, bin)

#### Load
- 저장되어있던 프로젝트를 로드하는 버튼 (json, bin)
